Featured Projects
Job Recommendation System

A full-stack web application that recommends jobs to users based on their skills and interests. The system includes role-based access control for job seekers, organizations, and administrators. It also integrates a machine learning recommendation engine through a Flask microservice.

Technologies: Python, Node.js, Express.js, Flask, Scikit-learn, EJS

House Price Prediction

A machine learning project that predicts house prices using historical housing data. The application includes data preprocessing, model training, and a user-friendly interface built with Streamlit.

Technologies: Python, Scikit-learn, Pandas, NumPy, Streamlit

WorkFaster

A desktop productivity application based on the Pomodoro technique. It helps users stay focused by managing work and break sessions through a simple interface.

Technologies: React, Electron, TypeScript, CSS
